# Visual review

- Before finishing visual changes, inspect the result in an actual Safari or Chrome desktop window. The narrow Codex sidebar is not a substitute for this check.
- Check a short laptop viewport as well as a taller desktop viewport. Keep the name, introductory sentence, portrait and surrounding artwork aligned without clipping or overlap.
- The development-only `/__desktop-review` route keeps a fixed desktop viewport inside the sidebar. Use it for the review handoff; the regular `/` route remains the website.
- Preserve the portrait's approved appearance, motion and transparent background. The surrounding 3D objects use matching monochrome ink grain.
- Keep changes local for review unless the user requests publication.
